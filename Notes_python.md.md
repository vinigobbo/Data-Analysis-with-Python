# Data Analysis with Python

## MATEMÁTICA BÁSICA:

-   **Retorno** = 1° Valor / Valor anterior - 1
-   **Média** = soma dos retornos / número de retornos
-   **Desvio** = retornos - média
-   **Soma dos quadrados** = somatório de todos os desvios ao quadrado
-   **Volatilidade** = raiz quadrada de (soma dos quadrados / número de
    retornos)

## TAGS UTILIZADAS:

-   `round(y, x)` - arredonda o dado com x casas
-   `for i in range()` - repete o i para todos os valores de uma lista
-   `len()` - conta quantidade de itens de uma lista
-   `sum()` - soma todos os valores de uma lista
